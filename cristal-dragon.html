      COMMENT JOUER

      Guide du chasseur de dragon

      Objectif : Atteins 50 000 points pour battre le dragon !

      📱 Mobile : touche la moitié gauche / droite de l'écran pour les flippers, le lanceur en bas à droite.
      💻 Clavier : ← → pour les flippers, Espace pour lancer, P pour pause, N pour mute.

      🎯 Bumpers : 3 cibles colorées, notes do-mi-sol.
      💎 Runes : 3 cibles à gauche, les activer toutes donne un bonus doré.
      🐉 Dragon : boss à 5 PV, le tuer donne 1500 pts.
      🎁 Bonus : activer les 3 runes = 10s de multiplicateur x2.
      🔥 Combo : enchaîne les touches pour monter jusqu'à x5.
